ef.embedder_adapters

ef.embedder_adapters¶

Concrete Embedder adapters and the DI seam.

Adapters are lazily-imported factory functions — heavy dependencies (openai, sentence-transformers) are imported inside the factory, never at module load, and live in optional extras. Importing this module costs only numpy + the stdlib.

  • openai_embedder() — OpenAI embeddings (sync + the async Batch API). Needs ef[openai].

  • sentence_transformers_embedder() — local PyTorch models. Needs ef[sentence-transformers].

  • http_embedder() — any remote HTTP embedding service (TEI, infinity, …). Stdlib-only.

  • cohere_embedder(), voyage_embedder(), gemini_embedder() — the Cohere / Voyage / Gemini hosted embedding APIs, spoken over their REST endpoints directly. Stdlib-only (no SDK dependency); each needs only an API key. The whole point of these adapters is translating the canonical InputType vocabulary to the vendor’s own task name.

  • as_embedder() — the single dependency-injection seam: turns a string (model name / openai: / cohere: / voyage: / gemini: prefix / URL), a bare callable, or an existing embedder into an Embedder.

The canonical task vocabulary (InputType) is translated to each vendor’s own name at the adapter boundary — that translation is the whole point of having adapters.

Example — the DI seam in action (no network / no heavy deps needed):

>>> import numpy as np
>>> from ef.embedders import Embedder
>>> e = as_embedder(lambda ts: np.ones((len(ts), 5)), model_id='ones@5')
>>> isinstance(e, Embedder)
True
>>> e(['x', 'y']).shape
(2, 5)
>>> as_embedder(e) is e          # an Embedder passes straight through
True

ef.embedder_adapters.as_embedder(x, **kwargs)[source]¶

Normalize x into an Embedder — the DI seam.

The single place every ef entry point coerces a user-supplied embedder argument. Accepts, in order:

  1. an existing Embedder — returned unchanged;

  2. a URL string (http:// / https://) — http_embedder();

  3. a provider-prefixed string — "openai:<model>", "cohere:<model>", "voyage:<model>" or "gemini:<model>" — the matching hosted-API adapter;

  4. the bare string "hashing" — the dependency-free HashingEmbedder (ef’s zero-install default);

  5. an "st:<model>" string, or any other bare model name — sentence_transformers_embedder() (the local neural default);

  6. a bare callable — wrapped in FunctionEmbedder (the imbed-embedder bridge).

Extra **kwargs are forwarded to the chosen factory.

Raises:

TypeError – if x is none of the above.

Return type:

Embedder

>>> import numpy as np
>>> e = as_embedder(lambda ts: np.zeros((len(ts), 2)), model_id='zero@2')
>>> type(e).__name__
'FunctionEmbedder'
ef.embedder_adapters.cohere_embedder(model='embed-v4.0', *, dim=None, api_key=None, batch_size=96, timeout=60.0)[source]¶

Build a Cohere-embeddings Embedder.

Talks to Cohere’s /v2/embed REST endpoint directly — no cohere SDK, no extra dependency. Cohere’s v3+ models require a task hint; this adapter supplies one for every canonical InputType and defaults to the document role when none is given.

Parameters:

  • model (str) – A Cohere embedding model name.

  • dim (int | None) – Matryoshka-truncated width (embed-v4.0 only). Omit for the model’s native width. The dim is part of the embedder’s identity — set it once here, not per call.

  • api_key (str | None) – Cohere API key. Falls back to CO_API_KEY / COHERE_API_KEY.

  • batch_size (int) – Texts per request (capped at Cohere’s 96 limit).

  • timeout (float) – Per-request timeout in seconds.

Return type:

Embedder

Returns:

An Embedder over the Cohere API.

ef.embedder_adapters.http_embedder(url, *, model_id=None, dim=None, normalized=False, batch_size=64, headers=None, timeout=30.0, payload_builder=<function _tei_payload>, response_parser=<function _tei_parse>)[source]¶

Build an Embedder over a remote HTTP service.

Defaults target the Text-Embeddings-Inference / infinity shape (a POST of {"inputs": [...]} returning a JSON list of vectors). For a different service, override payload_builder and/or response_parser.

Parameters:

  • url (str) – The embedding endpoint.

  • model_id (str | None) – Vector-identity string (defaults to "http:<url>").

  • dim (int | None) – Output width; inferred from the first response if omitted.

  • normalized (bool) – Whether the service returns unit vectors.

  • batch_size (int) – Texts per request (used with length-sorted batching).

  • headers (dict[str, str] | None) – Extra HTTP headers (e.g. an auth token).

  • timeout (float) – Per-request timeout in seconds.

  • payload_builder (Callable[[Sequence[str]], bytes]) – texts -> request body bytes.

  • response_parser (Callable[[Any], Any]) – decoded JSON -> array-like (n, dim).

Return type:

Embedder

Uses only the stdlib — no extra dependency.

ef.embedder_adapters.sentence_transformers_embedder(model_name='all-MiniLM-L6-v2', *, device=None, normalize=False, batch_size=128, model_path=None, query_prompt=None, document_prompt=None, prompt_names=None, dtype=None, **st_kwargs)[source]¶

Build a local sentence-transformers Embedder.

Instruction-tuned models (bge, gte, e5-instruct, Qwen3-Embedding…) are conditioned per input_type: pass a literal query_prompt (and, rarely, document_prompt), or map input types to prompts the model defines itself with prompt_names (e.g. {"query": "query"} for Qwen3-Embedding). Those roles are then advertised in honored_input_types, and the prompt text is baked into model_id. Only trust prompts on genuinely instruction-tuned models; on all-MiniLM they are expected to be a near no-op. Prefer these over wrapping the adapter in InstructionEmbedder: sentence-transformers knows the prompt’s length, so models that pool without the prompt tokens (INSTRUCTOR, GRIT) stay correct. Needs sentence-transformers >= 2.4.

Parameters:

  • model_name (str) – A sentence-transformers model name (also used in model_id).

  • device (str | None) – Torch device ("cuda" / "cpu" / "mps"); None auto-selects.

  • normalize (bool) – Whether to L2-normalize outputs. sentence-transformers does not normalize by default — set this truthfully.

  • batch_size (int) – Encoding batch size (smaller on CPU).

  • model_path (str | None) – A local filesystem path to load from instead of the hub — for air-gapped use. Loading still records model_name in model_id.

  • query_prompt (str | None) – Prompt prepended to input_type="query" texts (passed as encode(prompt=...)).

  • document_prompt (str | None) – Prompt for input_type="document" texts (usually none: the asymmetric pattern leaves documents bare). "" means an explicit empty prompt, which stops a model’s default_prompt_name from being applied to documents.

  • prompt_names (Optional[Mapping[str, str]]) – {input_type: name} of prompts defined in the model’s own prompts config (passed as encode(prompt_name=...)). An explicit prompt= / prompt_name= in a call overrides both.

  • dtype (Any) – Torch dtype (or its name, e.g. "bfloat16", "auto") to load the model in; names are passed through to transformers. By default, on a CPU device the model is loaded in float32: bf16 checkpoints (Qwen3-Embedding…) otherwise stay bf16, which is ~5x slower on CPUs without native bf16 matmul. Elsewhere the checkpoint’s dtype is kept. A dtype already present in model_kwargs ("torch_dtype" or "dtype") takes precedence over both this argument and the CPU default.

  • **st_kwargs (Any) – Forwarded to the SentenceTransformer constructor.

Return type:

Embedder

Requires sentence-transformers (pip install 'ef[sentence-transformers]').

ef.embedder_adapters.voyage_embedder(model='voyage-3.5', *, dim=None, api_key=None, batch_size=1000, timeout=60.0)[source]¶

Build a Voyage AI Embedder.

Talks to Voyage’s /v1/embeddings REST endpoint directly — no voyageai SDK, no extra dependency. Voyage embeddings are L2-normalized. Voyage distinguishes only query from document; a classification or clustering hint is simply not sent.

Parameters:

  • model (str) – A Voyage embedding model name.

  • dim (int | None) – Matryoshka-truncated width (the voyage-3.5 family and voyage-code-3 only). Omit for the model’s native width.

  • api_key (str | None) – Voyage API key. Falls back to VOYAGE_API_KEY.

  • batch_size (int) – Texts per request (capped at Voyage’s 1000 limit).

  • timeout (float) – Per-request timeout in seconds.

Return type:

Embedder

Returns:

An Embedder over the Voyage API.
